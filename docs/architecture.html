Karaoke: Architecture Diagram

API client "Karaoke" · https://mjhalim777.github.io/karaoke/ · Google Cloud project inbound-mote-354004 · Personal, non-commercial

① The phone calls search.list directly from the browser with a restricted API key. One call per search (maxResults 15).
②③ The queue lives in Firebase so the TV and every phone in the room see the same list in real time.
④ The TV plays each song by its video ID in the official YouTube embedded player. Playback uses no API quota.
Data: no accounts, no OAuth, no YouTube user data. Stored: video ID, title and an optional nickname for the current queue only.
